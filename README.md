# 智变 · 生产力跃迁

面向电脑展示的四幕交互作品：唤醒、产业重构、生产力实验、价值全景。前三幕保留 Three.js 程序生成的机械引擎、精密零件产线与二维协作实验；第四幕融合生产力关系场与决策实验，从数据、能力、产业和价值的联系，进入投入条件与收益的比较。全站围绕 AI 如何通过技术突破、要素重组与流程改进驱动新质生产力。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 生成 `dist/`，`npm run preview` 预览构建产物。`npm test` 检查教学模型的端点、单调性、守恒与输入边界。

## 操作

- 顶部导航、滚轮、上下方向键或底部按钮切换四幕。第四幕使用 `#panorama`，旧链接 `#frontier`、`#human` 仍指向第四幕。
- 第一幕“拆解智能核心”解释数据、模型、算力与应用；底部三项可探索技术、要素与价值的变化。
- 第二幕拖动分界线或底部滑块，联动缺陷标记与耗时条；点击三维工位或四个环节按钮查看解释。右侧切换“缺陷观察”，比较划痕、反光和缺口；“深入流程”解释输入、风险和反馈。
- 第三幕调整 AI 自动处理范围、人工复核强度，或使用三种预设；保存当前配置后可与新配置对照。“结果分析”绘制三档复核强度的权衡曲线，提供对比表和动态机制解释，内容可在区内滚动。
- 第四幕“价值全景”先展示生产力关系场。默认追踪智能制造路径；切换“空间总览”可拖动旋转，点击节点或“探索价值路径”查看数据、能力、产业、价值与人的判断如何连接。支持 Ctrl 加滚轮缩放、方向键旋转、加减键缩放、空格暂停和 Home 复位；三项历史数字可点击查看来源与适用边界。节点位置、大小与连线是机制示意，不编码数量或因果强度。
- 点击“进入生产力决策”或在第四幕内部向下滚动，调整 AI 应用率、数据质量、培训水平和人工复核强度；切换“流程 / 百件样本”，观察产出与质量的教学示意。点击、拖动收益地形或聚焦后用方向键选择应用率与数据质量；切换“时间轨迹”查看 0–24 个月的累计增量净收益。可载入“准备充分 / 仓促上线”预设，将当前参数存为 A、B 并比较结果和收益曲线。
- A/B 方案只保存在当前浏览器的 localStorage，再次保存覆盖对应槽位，不上传服务器；浏览器存储不可用时仅暂存当前页面，刷新会丢失。第四幕及结果分析区内滚动不触发整站换幕，输入控件的方向键用于自身操作。
- “查看证据”提供原始来源和模拟口径；右上角支持全局暂停动态和全屏。暂停会传递到关系场与决策实验，仍可操作参数和查看静态结果；离开第四幕或页面隐藏时停止其动画。各模块遵循系统减少动态效果偏好。

## 数据口径

真实事实与示意计算相互独立：

1. 制造业 85% 以上人工质检成本降低来自工信部优质中小企业梯度培育平台 2025-11-19 的《AI 无损检测技术赋能高压组件高可靠质检》企业案例。是系统集成后的单案例成效，非行业平均值；页面产线是精密零件流程演示，非案例设备复刻。
   https://zjtx.miit.gov.cn/zxqySy/tzggView?allx=7&id=016822aa67ee4f7782964bbbc95bcf73&type=classic
2. 第四幕“280 倍以上”来自 Stanford AI Index 2025（2025-04-07 发布）：达到 GPT-3.5 水平的 MMLU 成绩（64.8%）时，每百万 token 调用价格从 2022 年 11 月的 20 美元降至 2024 年 10 月的 0.07 美元。这是特定基准门槛下的调用价格，不表示所有任务能力相同，也不包含部署、培训和复核等企业总成本。
   https://hai.stanford.edu/news/ai-index-2025-state-of-ai-in-10-charts
3. “≈14%”采用 NBER 2023 年 6 月摘要对应的早期研究口径：研究分析 5,179 位客服人员，获得 AI 建议后，每小时成功解决的问题数平均增加 13.8%。主要部署发生于 2020 年 11 月至 2021 年 2 月。它是一家企业软件公司技术客服场景的分阶段部署准实验比较，员工决定是否采用建议；不是各行业通用增幅，也不是利润增长率，不与后续修订版本混用。
   https://www.nber.org/digest/20236/measuring-productivity-impact-generative-ai
   https://arxiv.org/pdf/2304.11771v1
4. “2 亿+”来自 EMBL-EBI 2022-07-28 官方发布：AlphaFold 数据库扩展至超过 2 亿条蛋白质结构预测，并向科研社区免费开放。数字表示开放预测规模，预测仍需置信度评估与实验验证，不能理解为经实验确认的发现、新药数量或生产率增幅。
   https://www.ebi.ac.uk/about/news/technology-and-innovation/alphafold-200-million/
5. 第二幕时间条为明确标注的教学设定，随对比比例线性插值。第三幕为确定性教学模型，计量判定正确性期望值与串行耗时，非实际合格品数量、真实节拍或企业预测。规则可在实验台与证据面板展开。
6. 第四幕决策实验使用独立的确定性教学模型：统一基线为每月 10,000 件、缺陷率 5%、月成本 50 万元、合格品单价 80 元；四项参数共同影响毛产出、缺陷率、成本与一次性投入。收益地形固定当前培训和复核，比较 AI 应用率与数据质量；累计增量净收益为“月份 × 月增量收益 − 一次性投入”。所有系数未经实证校准，未计入折现、需求波动、税费和设备折旧；百件样本是教学示意，不是真实观测或企业预测。模型公式和适用边界可在决策区展开查看。

## 实现

- `src/main.js`：四幕导航、比较交互、证据抽屉、可访问性与全屏。
- `src/scene.js`：单画布机械装置、形态转场、质检工位与射线热点。
- `src/lab.js` / `src/simulation.js`：教学实验与独立计算模型。
- `src/explore.js`：原理与生产要素拆解、产线流程面板、缺陷样本示意。
- `src/fusion.js`：第四幕组合、历史来源弹窗、内部滚动与模块生命周期。
- `src/relationship.js`：Canvas 2D 透视关系场、路径追踪、节点选择与可访问操作。
- `src/decision-lab.js` / `src/decision-model.js`：方案配置、生产过程显影、收益地形、时间轨迹、A/B 本地保存与独立教学模型。
- `src/style.css` 及各模块 CSS：桌面展览排版与各交互区样式。

三维几何与环境反射均程序生成，无外部模型或 HDR 依赖。WebGL 不可用时显示装置示意，二维内容与实验仍可操作。字体优先使用在线 Noto Sans SC，不可用时自动回退到系统中文字体。页面不包含登录、后台或聊天机器人。
